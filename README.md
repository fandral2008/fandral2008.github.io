# FANDRAL

Fandral 的公开专业履历与项目作品集，聚焦医学影像、医疗 AI、临床科研、发明专利与独立工程。

当前展厅包含公开可体验项目、开源工具与私有工程案例；“家庭强触达通信”只公开已验证能力与当前验证边界，不公开私有仓库、家庭网络或设备身份信息。

## 本地预览

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。

## 发布目标

仓库名称使用 `fandral2008.github.io`，通过 GitHub Pages 发布至：

<https://fandral2008.github.io/>

推送到 `main` 后，`.github/workflows/deploy-pages.yml` 自动发布静态网站。

## 内容边界

- 公开项目可以提供在线体验和源码链接。
- 私有项目只展示能力说明，不提供仓库地址。
- 专利成果只展示已核实的题名、角色、申请号或公开号与状态，不展示未公开的权利要求、实现细节或代码。
- 尚未冻结优先权的研究方法只做方向级介绍，不公开可复现参数与流程。
- 不在页面中放置真实临床数据、患者图像、身份信息或内部系统截图。
